## GGB 预览工具：新增「复制链接」按钮（index.html + local-index3.html）

**需求**：两个页面的底部按钮各拆成两块，左侧原按钮（复制 iframe 代码），右侧新增「复制链接」（只复制纯 URL）。

**已确认的决策**（用户逐项选定）：
- 原按钮文案缩短为 `复制 iframe`（原为「预览并复制链接」/「复制当前预览链接」），右侧固定 `复制链接`
- 带空格文件名仅把空格转 `%20`，中文保持可读（不用全量 encodeURI，裸空格在 Markdown/邮件会断链）
- 两个按钮都加「✓ 已复制」闪烁反馈（1.2s 复原，`.copied` 类变绿）
- 两按钮同色（蓝），靠文字 + title 悬浮提示区分

**实现要点**：
- 结构：`<div class="button-row">` 包两个 button，`.button-row > button { flex: 1 }` → 各占一半，垂直位置不变
- 新增 `id="copy-link-btn"` + `copyPlainLink()`；`copyCurrentLink()`（iframe 那路）内容格式一行未改
- `previewBtn.disabled` 的 5 处切换点全部同步给 `copyLinkBtn`（loadGgbFiles / 空列表分支 / 选中文件）
- `flashButton()` 用 `dataset.label` 缓存原文案，`WeakMap` 存 timer 防连点重入
- 链接基址仍是 `getBasePath()`（= origin + 当前目录），所以 GitHub Pages 下自动出 `wangl393.github.io/gitggb/`，Live Server 下出 `127.0.0.1:5500/`

**验证**：python http.server 8123 + playwright-core 驱动系统 Chrome，26 条断言全 PASS；服务端日志确认复制出的两条 URL（含 `%20` 空格路径）实际 GET 均 200，at.html 正常加载。无 pageerror。

**遗留可选项（未做，待用户决定）**：
- index.html 首屏加载后按钮仍为禁用，需点击文件节点才启用（原有行为，local-index3 会自动选第一个文件）
- 两页均无「复制纯链接」以外的批量复制功能
